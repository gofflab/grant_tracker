How it works

  1. Federal numbers (e.g. PAR-25-131, RFA-NS-26-001) are looked up on Grants.gov for exact dates, ceilings and agency, and the full NIH Guide notice is read.
  2. The announcement text is scanned for labeled fields: due dates, letters of intent, expiration, budget limits, project period, activity code, institutes, eligibility, limited-submission rules and contacts.
    3. {% if ai_available %}
  3. AI (Claude) reads the whole announcement too, which helps most with foundation calls and free-form pages. Only the announcement is sent.
    4. {% else %}
  4. AI reading is off. Add an ANTHROPIC_API_KEY to .env to have Claude read free-form foundation pages as well.
    5. {% endif %}
  5. You review a pre-filled form showing where each value came from, then save.

Some sites block automated reading. If a link fails, download the PDF and upload it, or copy the page text into the box.
